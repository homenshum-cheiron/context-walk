# Synthetic guideline on post-approval changes

This document is invented for testing. It is not a real regulation and names no real authority.

## 1 Scope

This guideline covers changes to an approved product after first approval.
It does not cover new applications.

## 2 Change categories

A change falls into one category. The category sets what the holder must file.

### 2.1 Minor changes

A minor change has no expected effect on quality.
The holder reports it in the annual summary.

### 2.2 Moderate changes

A moderate change may affect quality.
The holder files a notification 30 days before the change.

| Code | Change | Category |
|---|---|---|
| B.4.a | Tightening of a specification limit | Minor |
| B.4.b | Addition of a new test with its limit | Moderate |
| B.4.c | Widening of an approved specification limit | Major |

### 2.3 Major changes

A major change is likely to affect quality.
The holder must wait for approval before the change.
Row B.4.c in section 2.2 is a major change even though the table sits under moderate changes.

## 3 Documents to file

For each category the holder files the documents listed below.

### 3.1 For a notification

A comparison of the old and new limits, and batch data for two batches.

### 3.2 For prior approval

A comparison of the old and new limits, batch data for three batches, and a justification.

## 4 Definitions

Specification limit: the range a test result must fall in.
